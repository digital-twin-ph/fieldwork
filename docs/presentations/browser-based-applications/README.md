# Browser-based applications

_Created 2026-11-19 · Updated 2026-11-19_

A short deck, 11 slides, that introduces browser-based applications to an audience who knows desktop and web
applications. It explains where each kind runs and where the data goes, why the difference matters for field
epidemiology, what it costs, and how to tell which kind you are using. Fieldwork is the example.

The published deck is at <https://claude.ai/artifact/AkQEc9HAWQtxrA5BZs9zD7>. The files here are its source:
`project/deck.json` (order and sections), `project/deck.css` and one file per slide in `project/slides/`. Speaker notes
are in each slide's `<aside>`.

Before presenting, fill in:

- the presenter, event and date on the cover slide;
- the examples on slide 2 (`three-kinds`), chosen for the audience;
- the "Next" line on the closing slide, to match what follows.
