How it works

A browser is a computer inside your computer.

Modern browsers run full programs: maps, statistics, even a reasoning engine. A browser-based application uses that power instead of a server’s.

The technical names: JavaScript and WebAssembly run the program; the browser’s own storage (IndexedDB) keeps the data.

The key idea: today's browsers are capable computers in their own right. The same engine that plays video or runs an online game can fit a regression or draw a map. A browser-based application takes advantage of that. For a technical audience, mention JavaScript and WebAssembly as how programs run in the browser, and IndexedDB as where data is kept. For everyone else, “a computer inside your computer” is enough.
