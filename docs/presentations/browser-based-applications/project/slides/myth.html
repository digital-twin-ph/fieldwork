A common misunderstanding

“If it’s in a browser, my data is on the internet”

What people assume

Anything opened in a browser sends what I type to some company’s server.

What is true

That depends on the application. A browser-based application keeps the work on your computer; only the program came from the internet.

How to check for yourself: next slide.

This is the misunderstanding we meet most. People reasonably assume that a browser means the internet means a server. For web applications that's right. For browser-based applications it isn't: the program came from the internet, the data didn't go there. The next slide gives three questions anyone can ask to tell which kind they're using.
