Three questions

How to tell which kind you are using

1

Did you have to install it?

Yes: desktop. No: web or browser-based.

2

Does it keep working with Wi-Fi off, once loaded?

Yes: it runs on your computer. No: it needs a server to work.

3

When you save, where does it say your work went?

“On this device” is your computer. “Synced” or “uploaded” is a server.

Three questions anyone can ask. The second is the clearest test: turn Wi-Fi off and keep working. Fieldwork passes it. A nuance for a technical audience: a browser-based application may still fetch things from the internet, such as boundaries, satellite files or map tiles. That is data coming in when you ask for it; your own data is not sent out. Fieldwork's header says where your work is saved: “Saved on this device”.
