Three kinds of software

The same screen can hide three different arrangements

Desktop application

Installed on your computer. It runs there, and keeps its files there.

Example: Excel, QGIS, R

Web application

Opened in a browser, but it runs on a server far away. What you type travels there.

Example: an online survey platform, webmail

Browser-based application

Opened in a browser like a website, then it runs inside the browser, on your own computer.

Example: Fieldwork

Three kinds. A desktop application is what most of us grew up with: you install it, it runs on your machine. A web application looks like a website, but the work happens on someone else's server, and your data goes there. A browser-based application is delivered like a website, but once it arrives, it runs on your own computer, inside the browser. Fieldwork is this third kind.
