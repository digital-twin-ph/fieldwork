The trade-offs to know

Your browser holds the work

Clearing browsing data, or a different browser, means it is not there. Back up, or save to a shared repository.

One computer’s memory

Very large datasets are limited by your laptop, not by a data centre.

Sharing is a choice you make

Nothing syncs by itself. Colleagues see your work when you send a file or save it to a repository.

Some online sources need permission

A data service must allow browsers to read it directly; most open ones do, some do not.

Be honest about the costs. Because the data lives in your browser, clearing browsing data deletes it: that is why Fieldwork has Back up and Save to the repository. Big data is limited by your own laptop's memory. Sharing is deliberate: nothing goes anywhere until you send it, which is the privacy benefit seen from the other side. And a few online data sources don't allow browsers to read them directly, a web rule called CORS.
