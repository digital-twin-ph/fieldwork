The one question that matters

Where does the work happen, and where does the data go?

Your computer

Desktop: runs here, data here.

Browser-based: runs here, data here.

Only the program travels →

A server

Web application: runs there, data sent there.

Browser-based: only hands out the program, like a library lends a book.

For a browser-based application, the server delivers the program once. It never sees your data.

This is the slide to slow down on. Ask: when I press Run, where does the computation happen? When I save, where does the file go? For a web application, both answers are “on their server”. For a browser-based application, both answers are “on my computer”; the server is only where the program is fetched from, like a library lending a book: the library doesn't read what you write in the margins.
