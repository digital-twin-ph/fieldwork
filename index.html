From places to decisions

Build a small spatial analysis by connecting data, operations, and rules. Everything runs on this device.

  1. Explore. Select a node to see its inputs and settings.
  2. Connect. Click an output circle, then a compatible input circle. Click a connector to remove it.
  3. Experiment. Change the distance threshold or heat alert, then run again.
  4. Understand. Select a neighborhood on the map or table for its supporting evidence.
  5. Keep. Export a workflow to move it between devices. Export a run receipt for inputs, rules, and results.

This is a research example, not a validated public health policy. Distances are straight-line approximations, not travel distances. Logical English comparison is not implemented in this slice.

Keyboard: Tab to controls, Enter to activate. Selected nodes can be moved with arrow keys. Delete removes a focused node. Ctrl/Cmd+Z undoes an edit.
