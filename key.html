Your Fieldwork key

This is the public key of your Fieldwork identity. Add it to GitHub as a signing key, so anyone can check that the notes you sign are yours. It cannot be used to sign in to GitHub.

Open GitHub's page for a new key
  1. On GitHub, give it a title, such as Fieldwork.
  2. Set Key type to Signing Key.
  3. Paste the key and press Add SSH key.
  4. Back in Fieldwork, press Check the link.

This address carries no key. Scan the code again from Fieldwork's Identity dialog.
